# Rolex Submariner — «Погружение». Раскадровка

**Бриф:** Submariner в карандаше, бумаге, светящемся контуре, затем 2D → 2.5D → 3D; разборка на детали и сборка; финал — анимация логотипа; каждый этап подписан.
**Формат:** MP4 1920×1080, 60 fps, H.264 yuv420p, AAC. Длительность 70 с. Музыка + SFX синтезируются офлайн (numpy), 120 BPM, такт = 2 с.

**Единая нить — погружение.** Submariner — часы для дайвинга, поэтому каждый следующий стиль — шаг глубже: эскиз на поверхности листа → бумажные слои → тёмная глубина, где светится люминесцент → плоскость обретает слои, потом толщину → погружаемся внутрь часов (разборка) → ядро — корона. Сквозные носители: пузырьки воздуха и фиксированный индикатор «этап + глубина» (0 → 300 м; 300 м — заявленная водонепроницаемость Submariner).

**Постоянный индикатор (screen space):** внизу слева, одна позиция и оформление: `01 / 09 · КАРАНДАШНЫЙ ЭСКИЗ` + шкала глубины. Не привязан к камере. Плюс крупный кинетический заголовок каждого этапа слева от часов, оформленный в стиле этого этапа.

## Карточки планов (сокращённо)

1. **Карандаш 0–10.** Бумага, рядом лежащий карандаш и ластик (передний план, размыт), крошки графита. Камера медленно наезжает с поворотом −6°→0°. Звук: пиано-мотив + шорох графита по штрихам, тик механизма. Выход: последние штрихи → тень на бумаге — вход для бумажных деталей.
2. **Бумага 10–18.** Слои падают по долям такта (10.5, 11, 11.5…), каждый — «шлёп» бумаги. Тени растут с высотой. Камера наклоняется по диагонали. Заголовок «БУМАГА» — вырезанные буквы. Выход: на 18.0 с (сильная доля) — свет гаснет.
3. **Свет. контур 18–26.** Тёмно-синяя глубина, пузыри разных планов (ближние размыты, DOF), каустики. Обход камеры, безель делает щелчки. Заголовок неоновым однолинейным шрифтом. Выход: заливка с центра на 26.0.
4. **2D 26–32.** Плоский плакат, стрелки идут таймлапсом, лёгкий дрейф камеры. Выход: камера начинает наклон.
5. **2.5D 32–38.** Слои как плоскости в Three.js, видно, что толщины нет. Выход: слои сходятся.
6. **3D 38–46.** Толщина вырастает, PBR-металл, керамика, стекло; облёт 3/4. Выход: стекло приподнимается.
7. **Разборка 46–53.** Детали уходят по оси на доли такта, подписи появляются у якорей. Фокус ведёт по деталям.
8. **Сборка 53–59.** Обратный порядок, клики. Выход: камера к короне на 12 часах.
9. **Логотип 59–70.** Золото на чёрном, удержание с 67 до 70.

**Главный риск:** Three.js в headless Chromium (SwiftShader) — скорость и качество металла. Проверяется пробой одного 3D-кадра до сборки.
