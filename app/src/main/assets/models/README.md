# Модели

| Файл | Статус | Описание |
|---|---|---|
| `cattle_keypoints_fp16.tflite` | **Заглушка (placeholder)** | Детерминированно возвращает `(x=0.5, y=0.5, confidence=0.0)` для всех 12 ключевых точек независимо от входного изображения. Нужна только для того, чтобы приложение собиралось и запускалось целиком. Поскольку confidence всегда 0.0 (< порога `PoseValidator.minKeypointConfidence = 0.55`), **каждый кадр будет честно отбракован** — приложение никогда не покажет вес, рассчитанный на фиктивных точках. Сгенерирована скриптом `python/generate_placeholder_keypoint_model.py`. |
| `weight_regressor_fp16.tflite` | **Обучена на синтетических данных** | Небольшой MLP (вход `[1,6]` float32, выход `[1,1]` float32 — кг), реально обучен скриптом `python/train_weight_regressor.py` на данных из `python/generate_synthetic_dataset.py` (MAE на валидации ≈ 8.9 кг). **Это НЕ данные реальных взвешиваний КРС** — модель демонстрирует работающий пайплайн обучения → экспорта → инференса, но не подтверждает точность ±10 кг на реальных животных. |

## Что нужно для промышленного использования

1. **Keypoint-модель**: разметанный датасет фотографий КРС (боковая проекция,
   12 анатомических точек на кадр — см. `model/BodyLandmark.kt`), обучение
   архитектуры в духе YOLOv8-pose/MoveNet, экспорт в TFLite с входом
   `[1,256,256,3]` uint8 и выходом `[1,12,3]` float32 (нормализованные x,y,
   confidence). Заменяет `cattle_keypoints_fp16.tflite` этим же путём/именем.
2. **Регрессор массы**: переобучение `train_weight_regressor.py` на реальных
   парах "промеры с фото (прошедшие PoseValidator) ↔ контрольное взвешивание
   на весах", собранных на конкретной ферме/породе — см.
   `python/generate_synthetic_dataset.py` для формата CSV и
   `docs/ARCHITECTURE.md`, раздел 4.4.

См. также корневой `docs/ARCHITECTURE.md` для полной методологии.
